# DISCLAIMER

The Duality AI is an **original, theoretical design concept** by Kenneth
Lee Blum Jr.

- It is a design study. It has **not** been peer-reviewed, and no working
  system implementing it exists in this repository.
- The code in this repository is a **structural demonstration only** —
  deterministic stand-ins that show the flow of the architecture. It
  performs no real reasoning and no real moral judgment, and it must
  **never** be used to make, filter, or gate real decisions about real
  people.
- This system does **not** understand morality, and nothing in this
  project claims that it does. As the concept itself states: the machine
  follows a written library of guidelines; it does not know right from
  wrong. Any moral content belongs entirely to the human-written clause
  library.
- No claims of consciousness, awareness, sentience, or understanding are
  made for this design or its demonstration code. The "hemisphere"
  language is an organizational metaphor drawn from the author's design
  premise — see the premise note in Section 2 of [THESIS.md](THESIS.md).
- The logical/creative hemisphere split is the author's premise, adopted
  as a design metaphor; it is not presented as established neuroscience.

This project exists to state an idea precisely and in the open — including
its limits, which are set out in Section 6 of the thesis ("What the
Duality AI Is Not").
